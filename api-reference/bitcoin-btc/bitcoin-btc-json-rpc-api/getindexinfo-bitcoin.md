# getindexinfo - Bitcoin

This method returns the status of the optional block indexes, such as the transaction index and the coinstats index, including whether each is synced and its best block height.

## Parameters

| Parameter   | Type   | Required | Description                      |
| ----------- | ------ | -------- | -------------------------------- |
| index\_name | string | No       | Filter to a single index by name |

## Response

```json
{
    "jsonrpc": "2.0",
    "id": "getblock.io",
    "result": {
        "txindex": {
            "synced": true,
            "best_block_height": 830000
        },
        "coinstatsindex": {
            "synced": true,
            "best_block_height": 830000
        }
    }
}
```

## Response Parameters

| Parameter | Type   | Description                             |
| --------- | ------ | --------------------------------------- |
| jsonrpc   | string | JSON-RPC protocol version ("2.0")       |
| id        | string | Request identifier matching the request |
| result    | object | Object keyed by index name              |

### Per-Index Object

| Field               | Type    | Description                                  |
| ------------------- | ------- | -------------------------------------------- |
| synced              | boolean | Whether the index is synced to the chain tip |
| best\_block\_height | number  | Highest block the index has processed        |

## Use Cases

* **Capability Checks**: Confirm the transaction index is available
* **Readiness**: Confirm an index is fully synced
* **Diagnostics**: Investigate missing index data
* **Feature Gating**: Gate features on index availability

## Error Handling

| Error Code | Message           | Description                                  |
| ---------- | ----------------- | -------------------------------------------- |
| 403        | Forbidden         | Missing or invalid ACCESS-TOKEN              |
| -8         | Invalid parameter | A parameter is out of range or malformed     |
| -32601     | Method not found  | The method is not available on this endpoint |
| -32602     | Invalid params    | A parameter is missing or has the wrong type |
