# combinerawtransaction - Bitcoin Cash

This method combines multiple partially signed raw transactions for the same underlying transaction into a single fully or partially signed transaction. It merges signatures across inputs.

## Parameters

| Parameter | Type  | Required | Description                                           |
| --------- | ----- | -------- | ----------------------------------------------------- |
| txs       | array | Yes      | Array of hex strings of partially signed transactions |

## Response Parameters

| Parameter | Type         | Description                                      |
| --------- | ------------ | ------------------------------------------------ |
| error     | null\|object | Error object when the call fails, otherwise null |
| id        | string       | Request identifier matching the request          |
| result    | string       | Hex string of the combined transaction           |

## Use Cases

* **Multisig Assembly**: Merge signatures from separate signers into one transaction
* **Distributed Signing**: Combine partially signed transactions produced independently
* **Raw Workflows**: Aggregate signatures without moving to the PSBT format
* **Threshold Spends**: Assemble the required signatures for an m-of-n input

## Error Handling

| Error Code | Message              | Description                                                     |
| ---------- | -------------------- | --------------------------------------------------------------- |
| -22        | TX decode failed     | The raw transaction hex could not be decoded                    |
| -26        | Transaction rejected | The transaction failed mempool acceptance checks                |
| -25        | Missing inputs       | One or more referenced inputs do not exist or are already spent |
| -32603     | Internal error       | Node failed to process the transaction                          |
