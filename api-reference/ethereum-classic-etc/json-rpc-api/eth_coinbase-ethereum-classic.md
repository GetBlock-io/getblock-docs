# eth\_coinbase - Ethereum Classic

This method returns the client's coinbase address — the account that receives mining rewards. It requires the node to have a coinbase configured.

## Parameters

{% hint style="info" %}
This method does not require any parameters. Send the request with an empty `params` array.
{% endhint %}

use reqwest::Client;
use serde_json::{json, Value};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = Client::new();

    let response = client
        .post("https://shared.eu-central-1.getblock.io/<ACCESS-TOKEN>/")
        .header("Content-Type", "application/json")
        .json(&json!({
            "jsonrpc": "2.0",
            "method": "eth_coinbase",
            "params": [],
            "id": "getblock.io"
        }))
        .send()
        .await?
        .json::<Value>()
        .await?;

    println!("Result: {}", response["result"]);
    Ok(())
}

## Response

```json
{
    "jsonrpc": "2.0",
    "id": "getblock.io",
    "result": "0x82A618305706B14e7bcf2592D4B9324A366b6dAd"
}
```

## Response Parameters

| Parameter | Type   | Description              |
| --------- | ------ | ------------------------ |
| jsonrpc   | string | JSON-RPC version ("2.0") |
| id        | string | Request identifier       |
| result    | string | 20-byte coinbase address |

## Use Cases

* **Reward Routing**: Read where block rewards are paid
* **Node Config**: Confirm the configured coinbase
* **Diagnostics**: Audit miner setup

## Error Handling

| Error Code                                      | Message       | Description                                       |
| ----------------------------------------------- | ------------- | ------------------------------------------------- |
| -32000 / etherbase must be explicitly specified | No coinbase   | The node has no coinbase configured               |
| 403 / RBAC: access denied                       | Access denied | The GetBlock access token is missing or incorrect |
