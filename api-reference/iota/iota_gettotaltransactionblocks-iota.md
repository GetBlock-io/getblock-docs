# iota\_getTotalTransactionBlocks - IOTA

Returns the total number of transaction blocks the network has executed since genesis.

## Parameters

This method takes no parameters.

## Request

{% tab title="cURL" %}
{% code overflow="wrap" %}
```bash
curl --location --request POST 'https://shared.eu-central-1.getblock.io/<ACCESS-TOKEN>/' \
--header 'Content-Type: application/json' \
--data-raw '{
    "jsonrpc": "2.0",
    "id": "getblock.io",
    "method": "iota_getTotalTransactionBlocks",
    "params": []
}'
```

## Response

```json
{
    "jsonrpc": "2.0",
    "id": "getblock.io",
    "result": "2850000000"
}
```

## Response Parameters

| Field   | Type   | Description                        |
| ------- | ------ | ---------------------------------- |
| jsonrpc | string | JSON-RPC version ("2.0")           |
| id      | string | Request identifier ("getblock.io") |
| result  | string | Total executed transaction blocks  |

## Use Cases

* **Network Stats**: Display lifetime transaction count
* **Growth Tracking**: Measure throughput over time

| 403 / RBAC: access denied | Access denied    | The GetBlock access token is missing or incorrect |
