# system\_name - Kusama

Returns the name of the node client implementation serving the chain.

{% hint style="info" %}
Available over both the JSON-RPC (HTTP) and WebSocket interfaces.
{% endhint %}

## Parameters

{% hint style="info" %}
This method takes no parameters; send an empty `params` array.
{% endhint %}

{% tab title="Rust" %}
{% code title="example.rs" %}
```rust
use reqwest::Client;
use serde_json::{json, Value};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = Client::new();
    let response = client
        .post("https://shared.eu-central-1.getblock.io/<ACCESS-TOKEN>/")
        .json(&json!({
            "jsonrpc": "2.0",
            "id": "getblock.io",
            "method": "system_name",
            "params": []
        }))
        .send().await?
        .json::<Value>().await?;
    println!("{}", response["result"]);
    Ok(())
}
```

## Response

```json
{
    "jsonrpc": "2.0",
    "id": "getblock.io",
    "result": "Parity Polkadot"
}
```

## Response Fields

| Field  | Type   | Description                |
| ------ | ------ | -------------------------- |
| result | string | Client implementation name |

## Use Cases

* **Diagnostics**: Record the client name for support
* **Compatibility**: Adapt to client-specific behaviour
* **Fleet Audits**: Inventory client implementations

## Error Handling

| Error                     | Message        | Description                                       |
| ------------------------- | -------------- | ------------------------------------------------- |
| -32603 / Internal error   | Internal error | The node failed to return the client name         |
| 403 / RBAC: access denied | Access denied  | The GetBlock access token is missing or incorrect |
