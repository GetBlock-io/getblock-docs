# net\_listening - Moonbeam

This method returns a boolean indicating whether the client is actively listening for network connections. It is used as a lightweight liveness check for an endpoint.

## Parameters

{% hint style="info" %}
This method does not require any parameters. Send the request with an empty `params` array.
{% endhint %}

## Response

```json
{
    "jsonrpc": "2.0",
    "id": "getblock.io",
    "result": true
}
```

## Response Parameters

| Parameter | Type    | Description                                          |
| --------- | ------- | ---------------------------------------------------- |
| jsonrpc   | string  | JSON-RPC protocol version ("2.0")                    |
| id        | string  | Request identifier matching the request              |
| result    | boolean | true if the client is listening for peer connections |

## Use Cases

* **Liveness Probes**: Confirm an endpoint is reachable in a health-check loop
* **Failover Logic**: Route requests away from a node that reports it is not listening
* **Monitoring**: Alert when a node stops accepting peer connections
* **Connection Checks**: Validate connectivity before opening a WebSocket subscription

## Error Handling

| Error Code | Message          | Description                                    |
| ---------- | ---------------- | ---------------------------------------------- |
| -32603     | Internal error   | The node failed to report its listening status |
| -32601     | Method not found | The net module is disabled on the client build |
