# eth\_getBalance - Peaq

Returns the wei balance of an address at a block.

## Parameters

| # | Example                                      | Description            |
| - | -------------------------------------------- | ---------------------- |
| 0 | `0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045` | Positional parameter 0 |
| 1 | `latest`                                     | Positional parameter 1 |

## Response

```json
{
    "jsonrpc": "2.0",
    "id": "getblock.io",
    "result": "0x7c2562030800"
}
```

## Response Parameters

| Field   | Type   | Description                           |
| ------- | ------ | ------------------------------------- |
| jsonrpc | string | JSON-RPC version ("2.0")              |
| id      | string | Request identifier ("getblock.io")    |
| result  | varies | The method result (see example above) |

## Error Handling

| Error                     | Message          | Description                                       |
| ------------------------- | ---------------- | ------------------------------------------------- |
| -32602                    | Invalid params   | A parameter was missing or malformed              |
| -32601                    | Method not found | The method name is not exposed by the node        |
| 403 / RBAC: access denied | Access denied    | The GetBlock access token is missing or incorrect |
