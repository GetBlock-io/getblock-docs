# eth\_getBlockByHash - Peaq

Returns a block by hash, with full transactions or just hashes.

## Parameters

| # | Example       | Description            |
| - | ------------- | ---------------------- |
| 0 | `0xblockhash` | Positional parameter 0 |
| 1 | `false`       | Positional parameter 1 |

## Response

```json
{
    "jsonrpc": "2.0",
    "id": "getblock.io",
    "result": {
        "number": "0x1a4b7c",
        "hash": "0xblockhash",
        "transactions": []
    }
}
```

## Response Parameters

| Field   | Type   | Description                           |
| ------- | ------ | ------------------------------------- |
| jsonrpc | string | JSON-RPC version ("2.0")              |
| id      | string | Request identifier ("getblock.io")    |
| result  | varies | The method result (see example above) |

| 403 / RBAC: access denied | Access denied    | The GetBlock access token is missing or incorrect |
