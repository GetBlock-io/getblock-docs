# starknet\_specVersion starknet

This method returns the version of the Starknet JSON-RPC specification that the node implements. It is used to confirm compatibility before issuing version-sensitive calls.

## Parameters

{% hint style="info" %}
This method does not require any parameters. Send the request with an empty `params` array.
{% endhint %}

## Response

```json
{
    "jsonrpc": "2.0",
    "id": "getblock.io",
    "result": "0.8.1"
}
```

## Response Parameters

| Parameter | Type   | Description                                     |
| --------- | ------ | ----------------------------------------------- |
| jsonrpc   | string | JSON-RPC protocol version ("2.0")               |
| id        | string | Request identifier matching the request         |
| result    | string | Semantic version of the supported JSON-RPC spec |

## Use Cases

* **Compatibility Checks**: Confirm the node's spec version before calling newer methods
* **Client Negotiation**: Select request shapes that match the served spec
* **Diagnostics**: Report the spec version when filing an issue
* **Monitoring**: Track spec upgrades across an endpoint fleet

## Error Handling

| Error                     | Message          | Description                                       |
| ------------------------- | ---------------- | ------------------------------------------------- |
| 63 / UNEXPECTED\_ERROR    | Unexpected error | The node failed to return its spec version        |
| 403 / RBAC: access denied | Access denied    | The GetBlock access token is missing or incorrect |
