# eth\_syncing - Tron

This method returns the sync status of the node. It returns false when the node is fully synced, or an object describing progress while catching up.

## Parameters

This method does not accept any parameters.

## Response

```json
{
    "jsonrpc": "2.0",
    "id": "getblock.io",
    "result": false
}
```

## Response Parameters

| Parameter | Type              | Description                                                    |
| --------- | ----------------- | -------------------------------------------------------------- |
| jsonrpc   | string            | JSON-RPC protocol version ("2.0")                              |
| id        | string            | Request identifier matching the request                        |
| result    | boolean or object | false when synced, or a sync-progress object while catching up |

## Use Cases

* **Readiness Checks**: Confirm a node is synced before serving traffic
* **Sync Monitoring**: Track a node's catch-up progress
* **Load Balancing**: Route away from unsynced nodes
* **Diagnostics**: Detect a node that has fallen behind

## Error Handling

| Error Code | Message        | Description                                            |
| ---------- | -------------- | ------------------------------------------------------ |
| -32602     | Invalid params | A parameter is missing or has the wrong type or format |
| -32603     | Internal error | The node failed to process the request                 |
