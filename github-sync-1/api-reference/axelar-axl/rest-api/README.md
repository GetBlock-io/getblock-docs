# REST API

The Cosmos SDK REST (LCD) interface for Axelar: HTTP/JSON queries for accounts, balances, staking, distribution, and governance, plus Axelar's own cross-chain modules — `nexus` (chain registry, transfer fees, deposit addresses), `evm` (EVM chains, gateways, token info), and `reward`. Addresses use the bech32 `axelar1…` form.
