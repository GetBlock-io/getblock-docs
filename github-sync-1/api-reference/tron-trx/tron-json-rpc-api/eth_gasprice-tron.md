# eth\_gasPrice - Tron

This method returns the current price of Energy expressed as a gas price in SUN, hex-encoded. It maps TRON's Energy price into the Ethereum-compatible gas-price field.

## Parameters

This method does not accept any parameters.

## Response

```json
{
    "jsonrpc": "2.0",
    "id": "getblock.io",
    "result": "0xd2"
}
```

## Response Parameters

| Parameter | Type   | Description                                             |
| --------- | ------ | ------------------------------------------------------- |
| jsonrpc   | string | JSON-RPC protocol version ("2.0")                       |
| id        | string | Request identifier matching the request                 |
| result    | string | Hex-encoded Energy price in SUN, expressed as gas price |

## Use Cases

* **Cost Estimates**: Combine with an estimate to compute a fee
* **Fee Display**: Show the current Energy price
* **Compatibility**: Provide a gas price to Ethereum-style tooling
* **Monitoring**: Track the Energy price over time
