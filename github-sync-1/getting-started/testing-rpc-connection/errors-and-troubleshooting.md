# Errors and troubleshooting

### Connection issues

| Code                 | Error Message                               | Solution                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| -------------------- | ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 401                  | Missing token-id                            | The token segment of the URL is empty, malformed, or has stray characters (including a trailing space, or a missing token entirely). Copy the endpoint URL from your GetBlock Dashboard exactly as issued.                                                                                                                                                                                                                                                                                                                       |
| 401                  | Unknown token                               | The token isn't recognized on this host. This covers several causes: the token is simply wrong (typo), it was rolled or deleted, it was never issued, or — since access tokens are region-bound — it's a completely valid token, just issued for a different region than the host you're calling (`eu-central-1`, `us-east-1`, or `ap-southeast-1`). If you're sure the token is current and correct, check it matches the region shown for that endpoint in your Dashboard; if it might have been rolled, generate a fresh one. |
| — (no HTTP response) | Could not resolve host / DNS lookup failure | Your request never reached GetBlock. Check the host segment of the URL is spelled correctly, e.g. `<service>.<region>.getblock.io`, and matches one of the regions shown in your Dashboard.                                                                                                                                                                                                                                                                                                                                      |
| 429                  | Too many requests                           | Check your GetBlock account for usage limits. Upgrade your plan if necessary                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
